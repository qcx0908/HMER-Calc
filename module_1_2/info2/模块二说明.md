## 二、我负责的模块定位

模块 2 是后端「LaTeX → 数值结果」计算服务。接收模块 1 或 Android 端传来的 LaTeX 字符串，用 latex2sympy2 解析、sympy 计算，返回数值结果。对应 **C4（表达式解析）、C5（实时计算）、C6（结果封装）** 的服务端部分。

## 六、核心代码说明

### （一）模块二整体结构

```
app/calculation/
├── __init__.py      # 空文件，标记 Python 包
├── calculator.py    # 核心：LaTeX 解析 + sympy 计算
└── router.py        # 接口层：接收 HTTP 请求，调 calculator
```

分工：

| 文件 | 职责 | 是否关心 HTTP |
|---|---|---|
| calculator.py | 纯计算逻辑，输入 LaTeX，输出数值 | 不关心 |
| router.py | HTTP 接口，参数校验，调 calculator | 关心 |

分开的好处：

- 计算逻辑独立，方便单元测试（不需要起服务）；
- 以后换 Web 框架（比如 Flask），`calculator.py` 不用改；
- 以后换计算引擎（比如自己写解析器），`router.py` 不用改。

### （二）calculator.py 逐段说明

#### 1. 导入部分

```python
import math
import sympy
from sympy import sin, cos, tan, pi
from latex2sympy2 import latex2sympy
```

- `math` —— 判断 `nan` / `inf`
- `sympy` —— 符号计算
- `sin, cos, tan, pi` —— 三角函数和常量
- `latex2sympy` —— LaTeX 字符串 → sympy 表达式

#### 2. Calculator 类与 calculate() 方法

```python
class Calculator:
    def calculate(self, latex: str, mode: str = "deg") -> dict:
```

输入：

- `latex`：LaTeX 字符串，如 `\frac{1}{2}+\sqrt{9}`
- `mode`：`"deg"` 或 `"rad"`，控制三角函数用角度还是弧度

输出：一个 dict，包含 `value`、`value_latex`、`status`、`message`。

返回 dict 而不是 `CalculateResponse` 的原因：

- `calculator.py` 不依赖 pydantic，保持纯逻辑；
- 封装成 `CalculateResponse` 是 `router.py` 的事。

#### 3. 第一步：解析

```python
try:
    expr = self._parse(latex)
except Exception as e:
    return {
        "value": None,
        "value_latex": None,
        "status": "PARSE_ERROR",
        "message": f"解析失败: {e}",
    }
```

- 调 `latex2sympy2`，把 LaTeX 转成 sympy 表达式。
- 出错怎么办：捕获异常，返回 `status="PARSE_ERROR"`，不让异常抛到 router，避免 500。

#### 4. 第二步：角度制换算

```python
if mode == "deg":
    try:
        expr = self._to_radians(expr)
    except Exception as e:
        return {
            "value": None,
            "value_latex": None,
            "status": "COMPUTE_ERROR",
            "message": f"角度制换算失败: {e}",
        }
```

- sympy 的 `sin`、`cos`、`tan` 默认用弧度制。但用户输入 `\sin(30)` 时，意思是「30 度」。
- 所以 `mode="deg"` 时，要把 `sin(30)` 转成 `sin(30 × π / 180)`，让 sympy 按弧度算出正确值。

#### 5. 第三步：求值

```python
try:
    value_latex = sympy.latex(expr)   # 符号表达式的 LaTeX
    numeric = expr.evalf()             # 数值求值
    value = float(numeric)             # 转 Python float
    if math.isnan(value) or math.isinf(value):
        return {
            "value": None,
            "value_latex": value_latex,
            "status": "COMPUTE_ERROR",
            "message": "结果不是有限实数",
        }
    return {
        "value": value,
        "value_latex": value_latex,
        "status": "SUCCESS",
        "message": None,
    }
except Exception as e:
    return {
        "value": None,
        "value_latex": None,
        "status": "COMPUTE_ERROR",
        "message": f"计算失败: {e}",
    }
```

三个关键点：

① `sympy.latex(expr)` —— 把 sympy 表达式转回 LaTeX 字符串，放进 `value_latex`，Android 端用它渲染公式。
② `expr.evalf()` —— 把符号表达式求出数值。例如 `\frac{1}{2}`→`0.5`、`\sqrt{9}`→`3.0`、`2^{10}`→`1024.0`。
③ `float(numeric)` —— sympy 的数值类型转成 Python 标准 `float`，方便 JSON 序列化。

#### 6. _parse() 方法

```python
@staticmethod
def _parse(latex: str):
    parsed = latex2sympy(latex)
    if isinstance(parsed, tuple):
        parsed = parsed[0]
    return parsed
```

- 做什么：调 `latex2sympy2` 解析 LaTeX。
- 判断 tuple：`latex2sympy2` 不同版本返回值不同——旧版返回 `expr`，新版返回 `(expr, mathrm_dict)`。统一取第一个元素，兼容两种版本。

#### 7. _to_radians() 方法

```python
@staticmethod
def _to_radians(expr):
    trig_funcs = (sin, cos, tan)
    def convert(node):
        if not node.args:
            return node
        new_args = [convert(a) for a in node.args]
        if node.func in trig_funcs:
            return node.func(new_args[0] * pi / 180)
        return node.func(*new_args)
    return convert(expr)
```

- 做什么：递归遍历 sympy 表达式树，遇到 `sin`/`cos`/`tan`，把参数乘以 `π / 180`。
- 递归遍历示例：`sin(30)` → `30 × π/180 = π/6` → `sin(π/6)`；`cos(60)` → `π/3` → `cos(π/3)`。
- 最终：`Add(sin(π/6), cos(π/3)) = 0.5 + 0.5 = 1.0`。
- 为什么用递归：表达式可能嵌套，如 `\sin(30) + \sqrt{\cos(60)}`，要能深入到每一层找到三角函数。

### （三）router.py 逐段说明

#### 1. 导入部分

```python
from fastapi import APIRouter
from app.common.models import CalculateRequest, CalculateResponse
from app.calculation.calculator import Calculator
```

| 导入 | 用途 |
|---|---|
| APIRouter | 创建路由 |
| CalculateRequest | 请求体类型 |
| CalculateResponse | 响应体类型 |
| Calculator | 计算器 |

#### 2. 创建 router 和 calculator

```python
router = APIRouter()
_calculator = Calculator()
```

注意：

- 变量名必须叫 `router`，`main.py` 按这个名字 import。
- `_calculator` 是全局单例，进程内只创建一个，复用。

#### 3. 路由定义

```python
@router.post("/calculate", response_model=CalculateResponse)
def calculate(request: CalculateRequest) -> CalculateResponse:
```

FastAPI 做了什么：① 收到 POST `/calculate`；② 自动把 JSON 解析成 `CalculateRequest` 对象；③ 调用你的函数；④ 把返回值序列化成 JSON。

#### 4. 参数校验

```python
if request.mode not in ("deg", "rad"):
    return CalculateResponse(
        latex=request.latex,
        status="PARSE_ERROR",
        message=f"无效的 mode：{request.mode}（应为 'deg' 或 'rad'）",
    )
```

- 做什么：检查 `mode` 是否合法。
- `mode` 传错时，不能让它走到 sympy 里产生奇怪结果，要在入口拦住，返回明确的错误信息。
- 返回的是 `CalculateResponse`，`status` 是 `PARSE_ERROR`，不是抛异常。

#### 5. 调用计算器

```python
result = _calculator.calculate(request.latex, request.mode)
return CalculateResponse(latex=request.latex, **result)
```

`result` 是什么：Python 的解包语法，把 dict 展开成参数。

假设 `result` 是：

```python
{"value": 3.5, "value_latex": "\\frac{7}{2}", "status": "SUCCESS", "message": None}
```

那么 `CalculateResponse(latex="...", **result)` 等价于：

```python
CalculateResponse(
    latex="...",
    value=3.5,
    value_latex="\\frac{7}{2}",
    status="SUCCESS",
    message=None,
)
```

### （四）数据流

```
HTTP 请求
  {"latex": "\frac{1}{2}+\sqrt{9}", "mode": "deg"}
  ↓  FastAPI 自动解析 JSON → CalculateRequest 对象
  ↓  router.calculate(request)
  ↓  检查 mode 是否合法
  ↓  calculator.calculate(latex, mode)
  ↓  1. _parse：LaTeX → sympy 表达式
     2. _to_radians：deg 模式换算
     3. evalf：求数值
     4. sympy.latex：生成 value_latex
  ↓  返回 dict：{"value": 3.5, "value_latex": "...", "status": "SUCCESS", "message": None}
  ↓  router 封装成 CalculateResponse
  ↓  FastAPI 序列化成 JSON
HTTP 响应
```

### （五）关键设计点总结

| 设计点 | 说明 |
|---|---|
| `calculator.py` 不依赖 pydantic | 纯逻辑，方便单元测试 |
| `router.py` 只做参数校验和调用 | 职责单一 |
| 所有异常都转成 `CalculateResponse` | 绝不 500，符合 `ALL.md` 红牌项 |
| `mode` 在 router 层校验 | 入口拦截，避免无效值进入计算 |
| `_to_radians` 递归遍历 | 支持嵌套表达式 |
| 检查 `nan`/`inf` | 防止返回无意义结果 |
| `result` 解包 | 让 calculator 和 router 解耦 |
| `router` 变量名固定 | `main.py` 按这个名字 import |

### （六）总结

`calculator.py` 负责「LaTeX → sympy → 数值」，分三步：解析、角度换算、求值；`router.py` 负责「HTTP → 参数校验 → 调计算器 → 封装响应」。所有异常都转成 `status + message`，绝不 500。两个文件职责清晰，计算逻辑和接口层解耦，方便测试和替换。
