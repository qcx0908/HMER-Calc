# 模块二存储描述 —— 计算结果存哪里

## 一、存储结论

后端**不持久化存储**计算结果，而是通过 HTTP 响应把结果返回给调用方（模块三 / Android 端）。

| 位置 | 存什么 | 生命周期 |
|---|---|---|
| 内存中的 `CalculateResponse` 对象 | 一次请求的结果 | 请求结束就释放 |
| HTTP 响应 JSON | 返回给调用方 | 由调用方决定怎么存 |

后端本身不写数据库、不存文件。这是 `ALL.md` 契约里说的「接口无状态」。

## 二、数据流：结果从哪来、到哪去

```
POST /calculate
  {"latex": "\cos\frac{\pi}{2}+1", "mode": "rad"}
  ↓  router.py 收到请求，创建 CalculateRequest 对象
  ↓  调用 calculator.calculate(latex, mode)
  ↓  calculator.py 内部：
     1. latex2sympy2 解析 → sympy 表达式
     2. sympy 求值 → float
     3. 返回 dict：{"value": 1.0, "value_latex": "...", "status": "SUCCESS", "message": None}
  ↓  router.py 把这个 dict 包成 CalculateResponse
  ↓  FastAPI 把 CalculateResponse 序列化成 JSON
  ↓  HTTP 响应返回给调用方
```

结果从头到尾只在内存里，从不落盘。

## 三、代码层面：结果存在哪两个字段

看 `app/common/models.py`：

```python
class CalculateResponse(BaseModel):
    latex: str                        # 原样回显输入
    value: Optional[float] = None     # ← 数值结果存这里
    value_latex: Optional[str] = None # ← LaTeX 形式结果存这里
    status: str                       # SUCCESS / PARSE_ERROR / COMPUTE_ERROR
    message: Optional[str] = None     # 错误信息
```

两个结果字段：

| 字段 | 类型 | 存什么 | 谁用 |
|---|---|---|---|
| value | float | 数值结果，如 1.0 | Android 端直接显示数字 |
| value_latex | str | LaTeX 形式，如 1 | Android 端渲染公式 |

注意：`value_latex` 不是「另一个结果」，是**同一个结果的不同表现形式**。

## 四、calculator.py 里结果怎么产生的

```python
def calculate(self, latex: str, mode: str = "deg") -> dict:
    # 1. 解析
    expr = self._parse(latex)
    # 2. 角度换算（deg 模式）
    if mode == "deg":
        expr = self._to_radians(expr)
    # 3. 求值
    value_latex = sympy.latex(expr)   # ← 符号表达式的 LaTeX
    numeric = expr.evalf()             # ← 数值求值
    value = float(numeric)             # ← 转 float
    # 4. 返回 dict
    return {
        "value": value,           # ← 数值结果
        "value_latex": value_latex, # ← LaTeX 结果
        "status": "SUCCESS",
        "message": None,
    }
```

关键点：

- `value` 来自 `expr.evalf()`，是数值；
- `value_latex` 来自 `sympy.latex(expr)`，是符号形式的 LaTeX；
- 两者都是临时的，返回给 router 后就释放。

## 五、router.py 里怎么封装

```python
@router.post("/calculate", response_model=CalculateResponse)
def calculate(request: CalculateRequest) -> CalculateResponse:
    result = _calculator.calculate(request.latex, request.mode)
    return CalculateResponse(latex=request.latex, **result)
```

`**result` 是 Python 解包语法，把 dict 展开成参数：

```python
CalculateResponse(
    latex="...",           # 原样回显
    value=1.0,             # 来自 result["value"]
    value_latex="...",     # 来自 result["value_latex"]
    status="SUCCESS",      # 来自 result["status"]
    message=None,          # 来自 result["message"]
)
```

FastAPI 自动把这个对象序列化成 JSON 返回。
