## 二、测试一：POST /recognize —— 图片识别为 LaTeX

**1. 测试目的**：验证模块一（识别服务）能把一张手写公式图片转换成 LaTeX 字符串，并返回置信度。

**2. 测试输入**：

- 测试图：`sample1.png`（手写 `cos(π/2)+1`）
- 位置：交付文件夹根目录

**3. 测试命令**：

```powershell
cd C:\Users\孟飞扬\Desktop\交付包_模块一\交付包_模块一
python -c "import base64,json;print(json.dumps({'image':base64.b64encode(open('sample1.png','rb').read()).decode()}))" > body.json
$response = Invoke-RestMethod -Uri "http://127.0.0.1:8000/recognize" -Method Post -InFile body.json -ContentType "application/json"
$response
```

**4. 实际返回**：

```
latex      : \cos\frac{\pi} {2}+1
confidence : 0.9969229102134705
tokens     : {}
status     : SUCCESS
message    :
```

## 三、测试二：POST /calculate —— LaTeX 计算为数值

**1. 测试目的**：验证模块二（计算服务）能把 LaTeX 字符串解析并计算出数值结果，同时返回 LaTeX 形式的结果。

**2. 测试输入**：

```json
{
  "latex": "1+2*3",
  "mode": "deg"
}
```

**3. 测试命令**：

```powershell
$body = @{
    latex = "1+2*3"
    mode = "deg"
} | ConvertTo-Json
Invoke-RestMethod -Uri "http://127.0.0.1:8000/calculate" -Method Post -Body $body -ContentType "application/json"
```

**4. 实际返回**：

```
latex       : 1+2*3
value       : 7.0
value_latex : 7
status      : SUCCESS
message     :
```

## 四、两条测试合起来说明什么

- 测试一证明：图片能变成 LaTeX；
- 测试二证明：LaTeX 能变成数值；
- 两条都过，说明两个接口各自功能正常；
- **还差一步**：把测试一的 LaTeX 喂给测试二的接口，才算全链路通 —— 【接口问题】。
